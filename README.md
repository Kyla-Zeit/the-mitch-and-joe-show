# The Mitch & Joe Show

This project is a complete Angular application for The Mitch & Joe Show, featuring a polished dark UI, responsive layouts, and a booking-focused contact form. The site is optimized for both desktop and mobile, with particular care taken to ensure native mobile inputs (such as the date picker) behave correctly across browsers.

The application is structured using Angular’s component architecture for maintainability and scalability.

👉 **[View Live Site]https://kyla-zeit.github.io/the-mitch-and-joe-show/**

---

## 🚀 Features
- Fully responsive layout (mobile, tablet, desktop)
- Component-based Angular architecture
- Smooth scrolling navigation
- Native mobile-friendly contact form
- Accessible, dark-mode–friendly design
- GitHub Pages deployment via GitHub Actions
- Clean separation of layout, styles, and logic
